# 每日编程练习 · c-practice-daily

从零开始学编程的练习仓库：每天亲手敲一道题，编译运行通过后上传。

## 练法（每天 30 分钟）

1. **亲手敲**：照着题目把代码一个字一个字敲出来，不复制粘贴
2. **跑起来**：本地编译运行，看到正确输出才算过
3. **传上去**：当天 push 到 GitHub，绿格子就是勋章

## 文件命名

`day01_common_suffix.c`、`day02_xxx.c`……一天一个文件，文件名里写清题目。

## 编译运行（Windows）

```
gcc day01_common_suffix.c -o day01
day01.exe
```

编译没报错、运行输出正确，这道题才算真正拿下。
